# Tailwind CSS Project 1 — Personal Portfolio

A responsive personal portfolio website for **Muhammad Usman**, built with HTML and Tailwind CSS. The site showcases skills, stats, and contact information for a Data Analytics student seeking entry-level Data Analyst roles.

## 🔗 Live Demo
[muhammadusman2008.lovable.app](https://muhammadusman2008.lovable.app)

## 📌 About
This portfolio highlights:
- Introduction and role (Data Analyst | Python | PostgreSQL | Power BI)
- Quick stats — projects completed, records analyzed, certifications, job simulations
- A short bio on data analytics experience and background
- Contact details — location, degree, email, and phone number
- Links to GitHub and a downloadable resume

## 🛠️ Built With
- **HTML5** — page structure
- **Tailwind CSS** (via CDN) — styling and responsive layout

## 📱 Responsive Design
The layout adapts across three breakpoints:
- **Mobile** — stacked single-column layout, 2×2 stats grid
- **Tablet** — adjusted spacing and grid sizing
- **Laptop/Desktop** — side-by-side sections, 4-column stats grid

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/muhammadusman5814-dotcom/tailwindcss-project-1.git
   ```
